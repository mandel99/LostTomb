## Build

From this directory:

```powershell
.\build.ps1
.\build.ps1 -Verify
# Read-only link audit; no original executable is needed:
.\tools\Audit-CLink.ps1
# Optional historical hybrid workflow (not part of the default C build):
.\build.ps1 -Hybrid -OriginalExe 'PATH\Pharaoh.exe'
# Original-machine-code verification is also explicit opt-in:
.\build.ps1 -VerifyOriginal -OriginalExe 'PATH\Pharaoh.exe'
```

Mechanical C preparation preserves function bodies while normalizing symbols,
declaring overlapping memory lvalues, implementing integer p-code helpers,
and translating field slices. Ambiguous types and inferred pointer casts are
compilation models. In particular:

- Recovered register inputs and exception state still require ABI restoration.
- Address-based globals require the original data layout and initialization.
- External imports and the complete application entry/exit path still require
  linking and runtime reconstruction; a static archive does not resolve them.
- Unknown stack layouts use a local compilation model, not a verified frame.
- Consumed return values of functions inferred as `void` call a fail-closed
  diagnostic rather than silently return zero.
- The unavailable `CRect` layout uses an opaque byte type for compilation;
  MSVC's `long double` is not an x87 80-bit emulation.
- Original CRT stream fields use a separate `restore_legacy_FILE` layout,
  isolated from the current host CRT's opaque `FILE` implementation.
- Calling conventions, some overlapping argument slots, pointer interpretations,
  and 24-bit values need review before affected functions can run correctly.
