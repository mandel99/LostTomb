Shared arithmetic fault boundary checks
======================================

Run python restore/direct_c/cohort3_replay/arithmetic_faults/verify.py after the common C-only build. The data-driven15-input matrix executes native plus three exact compiled helpers (60 offline routes). No per-function compiler framework or host executable is used.

Normal signed percentage values, zero divisor, wrapped products, actual x86 divide-error/vector0, dividend/divisor registers and defined SHL flags are checked. Two continuations modify the actual interrupted CPU context and resume IDIV, then compare returned quotient and Cdecl/nonvolatile behavior. Physical C stack/code locations differ and are not claimed identical.

The previous C abort discrepancy and private strict before/after compilation are separately archived in the repair receipt. The production C algorithm is reused; its fault-only boundary preserves the native instruction behavior without undefined C signed division.
